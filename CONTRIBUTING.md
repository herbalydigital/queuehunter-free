# Contributing

Thank you for your interest in QueueHunter.

The QueueHunter source code is not published in this repository, so we cannot accept code pull
requests. You can still help:

- **Report bugs** with the bug report template ([SUPPORT.md](SUPPORT.md) lists what to include).
- **Ask questions or suggest features** with the question / feature template.
- **Report documentation problems** — a wrong command, a missing step or an unclear setting —
  as an issue. Small documentation pull requests (files under `docs/`, `README.md`) are welcome.

Please keep reports free of secrets and production data, and follow the security policy in
[SECURITY.md](SECURITY.md) for vulnerabilities.
